🚲 Ruta 360 - E-commerce de Ciclismo de Alto Rendimiento
Ruta 360 es una plataforma web moderna y minimalista diseñada para una tienda de bicicletas de élite y artículos de alto rendimiento. El proyecto se enfoca en la precisión técnica y la ingeniería de velocidad, ofreciendo una experiencia de usuario fluida y visualmente impactante.

🚀 Características Principales:
Arquitectura Modular: Separación limpia de preocupaciones (HTML5, CSS3 y JavaScript).

Diseño High-End: Interfaz en Dark Mode con acentos en Electric Lime, utilizando Tailwind CSS para un estilo responsivo y estilizado.

Catálogo Dinámico: Página de productos (Flota de Montaña) con sistema de filtrado en tiempo real por búsqueda de texto, categoría y rango de precio.

Gestión de Carrito: Sistema de compra funcional con persistencia de datos en localStorage, actualización de cantidades y cálculo automático de totales.

Sección de Servicios: Presentación técnica de servicios de taller y rescate en senderos mediante un diseño de Bento Grid.

Optimización Visual: Corrección de solapamientos en rejillas complejas para asegurar una navegación perfecta en dispositivos móviles.

🛠️ Tecnologías utilizadas:
HTML5 (Estructura semántica)

Tailwind CSS (Estilizado mediante utilidades y configuración personalizada)

Vanilla JavaScript (Lógica de filtrado, carrito y manipulación del DOM)

Google Fonts & Material Symbols (Tipografía y recursos visuales)
